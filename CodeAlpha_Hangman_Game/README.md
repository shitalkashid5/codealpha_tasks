#  Hangman Game

## Project Overview

Hangman Game is a simple console-based word guessing game developed using Python.

The computer randomly selects a word from a predefined list, and the player has to guess the word one letter at a time.

The player is allowed a maximum of 6 incorrect guesses.

##  Features

- Random word selection
- Letter-by-letter guessing
- Maximum 6 incorrect guesses
- Input validation
- Duplicate letter detection
- Correct and incorrect guess tracking
- Win and Game Over conditions
- Console-based interface

## Technologies Used

- Python
- Random Module
- Strings
- Lists
- Loops
- Conditional Statements
- Functions/Logic
