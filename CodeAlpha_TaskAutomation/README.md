# 📁 JPG File Organizer

##  Project Overview

JPG File Organizer is a simple Python automation project developed as part of the CodeAlpha Python Programming Internship.

The program automatically finds JPG and JPEG image files from a source folder and moves them into a separate destination folder.

##  Features

- Automatically detects JPG and JPEG files
- Creates destination folder automatically
- Moves image files using Python
- Reduces manual file organization work
- Simple and easy-to-use automation script

##  Technologies Used

- Python
- os module
- shutil module
- File Handling
- Conditional Statements
- Loops

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Create a `source_files` folder.
4. Add JPG or JPEG files inside the folder.
5. Open the terminal.
6. Run:

```bash
python file_organizer.py
